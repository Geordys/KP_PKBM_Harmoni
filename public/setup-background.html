✨ Background Hero Setup

Implementasi background foto sekolah pada hero section

1

📷 Siapkan Foto Sekolah

Ambil atau siapkan foto sekolah dengan:

  • ✓ Ukuran: minimal 1920x1080px (landscape)
  • ✓ Format: JPG atau PNG
  • ✓ File size: < 500KB (lebih baik)
2

💾 Simpan Foto dengan Nama Tepat

Rename file menjadi:

hero-bg.jpg

Kemudian simpan di folder:

/public/assets/images/
3

🔄 Clear Cache & Refresh Browser

Tekan Ctrl+Shift+Delete untuk clear cache, kemudian tekan F5 atau Ctrl+R untuk refresh.

✅ Implementasi Selesai!

Website siap menampilkan background foto sekolah dengan overlay yang memastikan text tetap terbaca. Tampilan akan menjadi profesional seperti website sekolah resmi.
