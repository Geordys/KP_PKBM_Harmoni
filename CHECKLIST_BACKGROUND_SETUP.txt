🎨 OPSI OVERLAY (OPSIONAL):

Jika ingin mengubah overlay, edit HTML:
   Cari: <div class="hero" id="home">
   Ubah ke salah satu:

   1. <div class="hero dark-overlay" id="home">        [Gelap - Untuk foto terang]
   2. <div class="hero light-overlay" id="home">       [Terang - Default sekarang]
   3. <div class="hero blue-overlay" id="home">        [Biru - Warna primary]
   4. <div class="hero school-overlay" id="home">      [Merah - Warna sekolah]
   5. <div class="hero no-overlay" id="home">          [Tanpa overlay]
   6. <div class="hero gradient-only" id="home">       [Hanya gradient]

   • Property: background-image
   • Property: background-attachment: fixed (parallax effect)
   • Property: background-size: cover
   • Pseudo-element: ::before untuk overlay
